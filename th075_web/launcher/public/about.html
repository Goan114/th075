关于此版本

东方萃梦想网页版，以日文原版 1.11 为目标，采用具名 C++ 游戏逻辑，支持键盘、手柄和格斗触控。

使用与永夜抄、风神录、花映塚、地灵殿共用的 SDL3 / WebGL2 渲染器。精灵顶点由 CPU 计算，按透明顺序合批，通过 glBufferData 上传。

开源项目

启动器、资源包管理和触控布局基于 YomotsuHisami/eagler-touhou 的公共实现，遵循 GPL-3.0-or-later。使用 SDL3、Emscripten、zlib、stb_vorbis、miniaudio 和 fflate；原版游戏资源及字体保留各自权利。
