# 萃梦想 WEB 1.0.0 发布验收

日文原版 1.11 的具名 C++ / Wasm 游戏已接入最终公共启动器与 SDL3 / WebGL2 平台。公网为 https://api.steinsgateon.com/ ，本地端口 3007。

版本：1.0.0（2026-10-12）；网页清单身份：41d6f7f5e38436f1e3a9c246；正式 Wasm SHA-256：8fce0c0fa6c71e6c870575e3a482dd7deeeb5daab5de30281dd9917cacc0589a。

十一名对战角色；原版十名 Story 可选角色（美铃原版没有 Story）；Story、Arcade、对人、对电脑、Training、Demo、Music Room、战绩、结局与原版格式 .rep 保存／播放。资源采用 th075.dat / th075b.dat，不混入汉化版 th075c.dat。

游戏调用具名 C++ 管理器／角色控制器。绘图由 CPU Sprite/HUD/Background 顶点，经 GfxInterface / ZunGraphics 提交共享 portable/sdl Renderer，再进入 WebGL2。原版 EXE、Unicorn 和第三方逆向参考用于开发对照，均不在发布执行路径。

前端保持最终版公共启动器的存档、录像、音乐、分辨率和触控布局。手机采用格斗方向轮盘及 A/B/C/D，可同时按住；A 确认、B 返回、ESC 暂停。默认 1280×960，启动前可切换 640×480。修正了页面编号和射击游戏触控帮助遗留文案。

原版音效通过 miniaudio / SDL3 播放，34 首 OGG 保留原版循环位置。首次安装约 334 MiB，四个下载并行，但按顺序附加文件并原子提交；失败保持原来的已安装包，后续启动无需重下资源。

验证证据：

- 205 份组件对照报告，共 14,256,133 项已报告检查；各报告保留实际执行的核心哈希和测试范围。
- 十名 Story 角色各七场，共 70 场流程到结局；另验证 Reimu 全流程、死亡续关、姓名输入、战绩和录像保存。流程用开发 KO 接口加速，战斗另有原版组件对照。
- 新存档 Arcade 连续六场与胜利对话、六轮录像保存。
- 1800 帧网页录制回放的双方游戏状态一致；原版录像格式、随机数与回合配置有独立原版对照。
- 实际音频引擎的音乐、静音、系统与角色音效输出通过。
- 正式版桌面与手机视口：自然进入训练、多指 A+B+D、松开、暂停、存档和退出重启通过。
- 真实 HTTPS 公网：安装资源后进入实际对战，上述操作和退出重启通过，重启时游戏资源 HTTP 请求为零。
- 四并发包安装：乱序下载、顺序附加、更新失败回滚、后续拒绝处理和已安装文件复用通过。
- 正式包资源清单、源码身份、全部资源哈希和导出检查通过；开发 probe 已移除。

完整证据索引：reference/release-acceptance.json。浏览器验收：artifacts/browser。原版组件对照：artifacts/cpp/verification。

手机验收使用 Chromium 视口和多点触控模拟，真机驱动、帧率、手感与听感需测试组复测。未提供独立原版 1.11 的 .rep 样本；现有状态／数值／图形／文件对照与网页回放通过，不代表所有外部录像或任意设备均已穷尽验证。
