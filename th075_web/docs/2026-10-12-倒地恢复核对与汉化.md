# 萃梦想 WEB 1.0.3：倒地恢复核对与汉化

发布日期：2026-10-12。游戏逻辑目标仍为日文原版 1.11；本次没有改变战斗、碰撞、输入恢复时间或渲染架构。

## 截图中的移动

用户截图中的 Spell Card 宣言出现在人物起身后的准备阶段。原版允许此时移动和冲刺（D），A／B／C 攻击仍被封锁，正式开打后才恢复攻击。不是把所有输入一直封锁到提示消失。

原版完整战斗循环对照使用真实原版 .rep 初始化，在空中最后一次受击后，连续按住方向和 A／B／C／D。十一名角色分别在对战和故事规则下运行，共 9,482 帧；逐帧比较位置、动作、阶段、倒计时、输入掩码及战斗标志，全部通过。样本中准备阶段于第 290 帧进入，实际移动于第 291–298 帧开始，正式开放攻击在第 430 帧进入 Active。故事规则对照使用中立对手；真实故事对手和键盘／触控另外通过浏览器流程验证。

证据：artifacts/cpp/verification/knockdown-flow-original.json，以及 artifacts/browser/language-ja-flow.json 和 language-lang_zh-hant-flow.json。此结果核对了该恢复路径，不能证明每种可能输入都没有问题。

## 汉化选项

选择萃梦想卡片后，在游戏语言中选择“中文（繁體，本地漢化）”，然后启动。默认日文。切换语言需先退出游戏；无需另外导入汉化包。存档和录像共用，语言选择会记住。

汉化来自当前文件夹的 th075c.dat，主要文字为繁体 GBK。接入菜单、人物画面、符卡、音乐说明及故事文本；离线烘焙 1,727 个字码的五种字号，共 8,635 份字形，浏览器运行不依赖 Windows 字体。中日文混合文本使用明确标记，不会将日文录像名字当成 GBK。

旧汉化与日文 1.11 存在脚本差异：使用日文 1.11 的全部标签、指令种类、参数、表情、等待、音乐、声音及分支，替换对应文本。三句汉化缺失对白由 reference/chinese-text-supplement.json 补齐；卡片／音乐索引及人物精灵尺寸分别校验。没有载入汉化 EXE 或替换战斗逻辑。

新增汉化压缩图文约 87.9 MiB，字库约 3.5 MiB。字库作为独立资源读取，原有启动数据包保持逐字节一致，兼容未更新的本地资源与旧缓存启动器。首次更新会安装这部分新增资源；原有日文、音乐资源无需重新下载。安装后从浏览器本地数据库读取。清除站点数据仍会移除玩家自己的本地存档，更新或语言切换不会。
