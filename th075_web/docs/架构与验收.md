# 萃梦想最终架构与验收

游戏管理器与角色控制器使用具名 C++ 接口。动画、指令、物理运动、攻击碰撞、弹幕／召唤物、CPU、剧情、回合规则、录像和场景由游戏层负责；SDL3 平台负责文件、输入、音频和图形。

渲染路径：C++ / Wasm 游戏 → CPU Sprite / HUD / Background 顶点 → ZunGraphics / GfxInterface → 共享 SDL3 Renderer → WebGL2 → Canvas。共享 Renderer.cpp 与本地最终版基线相同；GraphicsState.hpp / Shaders.hpp 的灰度调制扩展有独立原版像素验证，变更哈希见 shared-architecture-extensions.json。资源来自 th075.dat / th075b.dat（日文 1.11）；th075c.dat 不参与运行。

关卡与菜单切换按原版状态执行。图形目标使用 GPU 截图，按透明顺序合批并直接上传；帧调度使用共用固定 60 Hz 与受限补帧；音频使用 miniaudio 混音到 SDL3。音乐 OGG 保留原版循环起止样本，音效来自三个原版音效 bank。文字来自离线 GetGlyphOutline 原字形数据，运行时无 GDI 字体依赖。

验证记录：

- artifacts/cpp/verification：角色、共同战斗、资源、输入、菜单、录像与渲染逐项原版对照；各报告标明边界和实际核心哈希。
- artifacts/browser/full-flow.json：实际应用录像录制／回放 1800 帧状态、完整 Reimu 剧情到结局与战绩／录像保存、死亡续关、各模式和十一角色。
- artifacts/browser/story-routes.json：十名原版可选剧情角色各七场完整路由到结局；美铃原版不提供 Story 选项。
- artifacts/browser/arcade-flow.json：新存档 Arcade 连续六场、胜利台词与原版格式录像保存。
- artifacts/browser/audio.json：实际 SDL 音乐／静音与原版音效 PCM 输出。
- artifacts/browser/candidate-launcher.json 和 production-launcher.json：最终公共启动器真实 RAF、选人／训练、1280×960、手机多指按住／松开、暂停、本地保存、退出再启动、安装后的资源读取。

KO 注入只在开发验证构建用于缩短流程测试。正式构建关闭 TH075_DEVELOPMENT_HARNESS，并检查所有 probe 导出均不存在。1:1 的依据是所列原版状态／数值／顶点／文件对照；这些样本无法证明任何机器、任何录像都绝无差异。未提供独立的原版 1.11 录像样本，已完成原版格式和回合配置对照以及网页录制回放。手机浏览器模拟不能替代真实手机驱动与延迟测试。
