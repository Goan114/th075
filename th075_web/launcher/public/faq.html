常见问题

如何开始？

点击卡片、启动游戏。首次会安装游戏资源，之后从当前浏览器的本地数据库加载。

手机操作

左侧轮盘输入方向，右侧 A / B / C / D 支持多点同时按住。菜单轮盘选择、A 确认、B 返回、ESC 暂停。触控设置可调整按键位置和大小。

电脑操作

方向键移动，Z / X / C / D 对应 A / B / C / D。可在游戏内 Option 修改键盘、手柄设置。Ctrl 跳过对白。

存档和录像

原版 score.dat / config.dat 和 .rep 格式，保存在当前浏览器的本地数据库；不会上传，也不会被其他玩家看到。清理网站数据前请导出备份。

画质

默认 1280×960，可在启动器切换 640×480。游戏逻辑保持原版每秒 60 次更新。
