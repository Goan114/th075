# 萃梦想 WEB 1.0.4：画面缩放与清晰度

本次核对了原版图片尺寸、原版过滤设置、CPU 精灵顶点，以及最终启动器和公网的显示尺寸。修复位于显示布局与前端选项，C++ 游戏和共享 SDL3 / WebGL2 渲染器的生产 Wasm 与 1.0.3 相同。

## 原因与原版对照

用户截图为 1920×1080，游戏区域为 1440×1080。原版逻辑画面为 640×480，因此素材被放大到 2.25 倍；内部 1280×960 的画面还会被网页放大到 1.125 倍。非整数倍率让源图的一像素笔画呈现不同宽度，放大的低分辨率字也更容易显得模糊。

选人立绘为 512×512，角色说明与招式图集为 512×1024，保留 32 位颜色和原始图片尺寸。中文与日文选人图集没有经过缩小处理。原版 Graphics::SetDefaultStates（0x401540）调用 SetTextureFilter(1)，使用点采样；当前网页选人画面也使用点采样。提高内部渲染分辨率可以改善几何绘制，但不能增加这些位图文字本身的细节。

## 修复

- 默认清晰整数缩放。1920×1080 / DPR 1 下显示为 1280×960（2 倍），居中并留边。
- 启动页新增“画面缩放”，可切换为铺满游戏区域并保存选择。
- 画面宽高和位置按设备像素计算，响应窗口大小与手机旋转。
- 小触屏若整数倍率会缩得过小，自动适配可视区域。DPR 2.75 的 390×844 竖屏保持约 390×292 的游戏区域。
- 保留 1280×960 / 640×480 内部渲染选择和原版点采样；继续使用共享 SDL3 / WebGL2 渲染器。

主要源码：sdl-runtime/display.mjs、sdl-runtime/managed.mjs、launcher/src/launcher/game-preferences.mts 和 app.mts。新增运行模块已列入发布清单与离线缓存。

## 验证

1. tests/cpp/graphics.test.mjs：原版 5,000 组精灵／透视／条带顶点样本，15,000 次绘制比较；900 次混合／透明／深度状态比较，均通过。
2. tests/sdl/crisp-presentation.test.mjs：真实繁体选人场景分别使用 640 和 1280 内部渲染，显示至 1280×960。整帧 9,830,400 个颜色通道与直接像素复制一致，差异为 0；验证了窗口缩放与铺满模式。
3. tests/sdl/display-launcher.test.mjs：正式生产运行模块与共用启动器，旧偏好默认值、显示设置保存、汉化选人、DPR 2.75 手机横竖屏与小屏适配通过。
4. tests/sdl/launcher-language.test.mjs：桌面／手机中日文切换，存档与录像保持，已安装资源零重复下载。
5. tests/sdl/upgrade-launcher.test.mjs：1.0.3 → 1.0.4，存档、录像字节保持；游戏资源重复下载数为 0。保存对照先自然进入标题，避开原版首次解锁标题音乐时写入记录的时机差异。
6. scripts/verify-release.mjs：发布文件哈希、199 个 C++ 源文件、146 个头文件及生产 Wasm 校验通过；不包含开发探针或 x86 / D3D 运行时导入。

浏览器证据：artifacts/browser/crisp-presentation.json、display-launcher.json、launcher-language.json、upgrade-1.0.4.json、release-static.json。公网验收与当前部署身份另见 public-display-1.0.4.json 和 reference/release-acceptance.json。

## 范围

此更新只涉及显示方式与界面。13 场完整原版录像（226,898 帧）为之前的游戏逻辑证据，本轮没有重跑。浏览器测试使用桌面 Chromium 和软件 GPU；手机布局及旋转使用设备模拟，手机真机驱动和帧率仍由测试组复测。公网显示验收复用了哈希已校验且与旧版相同的游戏资源，不作为首次 CDN 下载验收。

原版位图的细节上限仍然存在；本次消除不均匀放大，不会生成额外的高清纹理。

## 测试组操作

刷新公网 https://api.steinsgateon.com/?game=th075，确认左上角版本为 1.0.4；如果第一次刷新仍显示 1.0.3，再刷新一次，让已安装的网页外壳更新。启动器选择“清晰整数缩放”或“铺满游戏区域”。存档与录像无需重新导入。
